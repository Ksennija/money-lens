# Test Case: Successful user registration with valid email and password

**Preconditions:**

- User is on the registration page
- No existing account is associated with the email being used

**Test Data:**

- Email: valid, unused email address (e.g. `newuser@example.com`)
- Password: valid password meeting system requirements

**Steps:**

1. Navigate to the registration page
2. Enter a valid, unused email address
3. Enter a valid password
4. Submit the registration form

**Expected Result:**

- The system displays the message: "The registration is succeeded"

**Priority:** High
**Type:** Positive / Functional
