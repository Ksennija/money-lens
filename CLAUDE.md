Money Lens

This project is for personals who earn enough, but don’t understand why they don’t save.

A web application that imports total income and banking transactions, categorizes spendings and shows the user how spending has changed compared to last month.

Lanquage: Typescript for both FE and BE.

Tools: React for frontend and NodeJS for backend

Folders: Monorepo: /frontend for the FE project and /backend the BE project

This thing should be done consistently: Automatically categorize every banking transaction into the correct spending category.
